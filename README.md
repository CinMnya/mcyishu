## 一、这个模组在做什么

它把三套彼此关联的东方术数做成了可玩的系统：

- **命理**——每个人、每只怪、每座建筑都有一张属于自己的八字命盘；
- **风水**——世界被不规则的风水域切开，房子可以被「读」成户型图并被打分；
- **六爻**——用铜钱起卦，得到指向探索的线索，而不是坐标。

三套系统共用同一套底层语言（天干、地支、五行、八卦），所以它们之间是**通的**：

你的喜用神决定你在哪个风水域里更舒服，你的命盘决定卦象对你是吉是凶。

### 最核心的一条设计原则

> **同一个世界种子下，所有结果完全一致、可复现、可分享。**

这条原则不是口号，它被实现成了一条硬约束：

- 全模组**只有一个随机源**——`worldSeed`；
- 所有「随机」都是从 `种子 + 类型 + 维度 + 主体 + 限定 + 子项` 这个稳定键

  哈希出来的；
- **绝不**使用 `UUID`、现实时间、游戏刻、玩家行为计数作为随机输入；
- 基础数据**一个字节都不存盘**，每次从种子重算；只有玩家主动修改的东西才写存档。

结果是：你可以把「我在第 37 天问到的卦」发到论坛上，别人在同一个种子的世界里、

同样的日子、同样的时辰问同一件事，会摇出**一模一样的卦**。

## 二、玩法循环

```
进入世界 → 拿到命盘玉简 → 查看自己的八字
         ↓
用风水罗盘寻找吉地 → 建宅 → 观气台扫描户型 → 按建议改造
         ↓
用铜钱起卦 → 得到线索 → 探索、寻矿、战斗、交易
         ↓
找到自然建筑与十二处遗迹 → 读取它们的命盘、风水、卦象
         ↓
应对太岁、龙脉、每日宜忌、建筑渡劫
         ↓
后期：逆天改命、轮回转生、占领龙脉
```

模组的全部交互都通过**物品、方块、界面**完成。

| 想做什么      | 怎么做                   |
| --------- | --------------------- |
| 查看自己的八字   | 命盘玉简 或 按 `B`          |
| 勘测脚下地块的风水 | 风水罗盘（对空气右键）           |
| 扫描一栋房子的户型 | 风水罗盘（对着门右键）           |
| 常驻查看宅子风水  | 观气台（右键）               |
| 找龙脉       | 寻龙尺（右键，给方向不给坐标）       |
| 起卦        | 铜钱 / 蓍草 / 龟甲 / 日晷（右键） |
| 看别人的命     | 窥命符（对生物或玩家右键）         |
| 祭祀、净化宅气   | 香炉（右键上香）              |
| 化解太岁      | 在太岁方位上立石敢当            |
| 红石自动化     | 卦盘（六个方向各输出一路爻位信号）     |
| 导出命盘文本    | 命盘界面里的「导出全文」          |

## 四、系统一览

###

**四柱八字**由虚拟生辰推出——年柱用公元 4 年为甲子年推算，月柱走「五虎遁」，

日柱以儒略日数为轴，时柱走「五鼠遁」。整套历法写死在

`fate/FateCalendar.java` 里，可以逐行核对。

**身强身弱**看「帮我的力量 vs 耗我的力量」，五行权重按柱位加权

（月令最重）并把地支展开成**藏干**（本气 0.6 / 中气 0.3 / 余气 0.1）。

**喜用神**分两步取：先按扶抑定主判，再按调候补一个次喜

（冬月生人喜火、夏月生人喜水）。用神系数直接决定环境增益：主用神 ×1.30、

次喜 ×1.15、忌神 ×0.78。

**神煞**实现了十项：天乙贵人、文昌贵人、禄神、将星、华盖、羊刃、劫煞、亡神、桃花、驿马。

它们不只是命盘上的一行字——交易折扣、掉落、移速、经验、被怪盯上的概率都受其影响。

**大运流年**：阳年干顺排、阴年干逆排，起运岁由稳定哈希确定；流年每 360 游戏日一换、

流月每 30 日、流日每 1 日、流时按维度的时间体系。**跨维度时本命八字不变，流运按维度重算。**

**四种改命手段**语义各不相同：

| 手段 | 含义         | 代价             |
| -- | ---------- | -------------- |
| 伪命 | 伪造一张命盘给别人看 | 只对外生效，自身不改     |
| 逆命 | 把忌神当喜神用    | 短期爆发，长期积煞      |
| 轮回 | 重掷命盘       | 次数累加，每次换来的命更极端 |
| 改命 | 指定一个新生辰    | 不可逆            |

### 4.2 风水

**风水域**用**确定性 Voronoi + 分形噪声扭曲**划分：晶格边长 192 格，

每格一个抖动过的「脉眼」，查询点先用三层 fBm 噪声推歪再找最近脉眼。

所以域界是蜿蜒曲线，不是规整的多边形——**不按区块划分**。

每个域有四属性（气 / 煞 / 阴 / 阳）与五行偏向。下界的煞气整体上调、

阳气下调；末地则一切五行都弱。综合评分与吉凶五档

（大吉 / 吉 / 平 / 凶 / 大凶）直接决定：

作物生长、刷怪、交易价格、幸运、恢复，以及**夜里是否出阴煞**。

**户型扫描**（`fengshui/HouseScanner.java`）分五步：三维洪水填充圈定室内 →

逐列求楼板与顶 → **把门当墙**做二维洪水填充切房间 → 数家具认功能 → 跑六条阳宅规则评分。

六条规则分别是：大门朝向、中宫是否被卫厕占压、卧室是否冲门、厨卫是否相邻、

卫浴是否近门、宅形是否缺角。每一条都给出**问题说明 + 改造建议**，

不是一个分数了事。

**龙脉**是一条 14 段的蜿蜒带子，每段 220 格，**每年游走一次**。

站在上面有龙气加成，可以立契占领；过了年契约失效，得重新去找。

**太岁**每年坐镇一个方位（由年支决定），在那方位上动土会招煞，

立**石敢当**即可化解。判据是「以世界原点为心的 45° 扇形 + 64 格距离门槛」——

留出绕开的余地，因为一个无法规避的惩罚不叫规则，叫骚扰。

**每日宜忌**从流日干支推出，宜 2~~3 条、忌 2~~3 条，

遵守有加成、违反会积煞。它给每一天一个不同的节奏。

### 4.3 六爻

**起卦**三种方式：铜钱六掷（三枚铜钱摇六次，三背为老阴、三正为老阳，

动爻由钱面决定）、时间起卦、外应起卦。

外应起卦带的是**环境指纹**而不是骰子：朝向、脚下的方块、天候、坐标、游戏日。

站在同一个位置朝同一个方向、天气相同，外应就完全一样。

**装卦**是完整实现的：八卦二进制编码、纳甲表（乾纳甲壬、坤纳乙癸、

震庚巽辛坎戊离己艮丙兑丁，阳卦顺行阴卦逆行）、六亲（以卦宫五行为基准）、

六神（由日干定起点，甲乙起青龙、丙丁起朱雀……）、世应（按八宫位次）、

旬空（日柱所在旬轮空的那两个地支）、旺衰（旺相休囚死，以月令为基准）。

**六十四卦全表**在 `liuyao/Hexagram.java` 里，包含卦名、卦辞、吉凶倾向、

八宫归属与宫位次。八宫按京房分类：乾坎艮震巽离坤兑，每宫八卦

（本宫、一世、二世、三世、四世、五世、游魂、归魂），世应位置随之确定。

**取用神**按问事类型：寻矿看妻财、寻路看父母、战斗看官鬼、交易看妻财、

附魔看父母、天气看父母、寻人看兄弟、寻遗迹看子孙、求医看子孙、求平安看子孙。

**解卦输出五类线索**：方位、趋向（群系）、层高（Y 带）、时窗、风险。

**不给坐标。** 还会按「随机性等级」进一步模糊化——低档线索清晰，

混沌档只给你一个大致方向。

**反噬**：每日问卦超过上限后依次加重——信息模糊 → 伪卦 → 天雷 → 失明 → 引怪。

五档全部是短时可恢复、不掉东西的。反噬的目的是提醒「你问得太勤了」，

不是毁掉玩家的存档。

**卦盘方块**是本模组的红石接口：六个方向各输出一路爻位信号

（北=初爻、东=二爻、南=三爻、西=四爻、上=五爻、下=上爻），

爻为阳输出 15、为阴输出 0。红石电路可以直接读一整套卦象。

### 4.5 生物命理

每种生物类型有一套**算法 DNA**，**只看注册名**——不看血量、不看攻击力、

不看是不是亡灵。理由很实在：一旦 DNA 依赖生物属性，整合包一改数值，

全世界的生物命盘就全变了，「可复现」立刻失效。

DNA 的八项参数：天干起始偏移、地支规则、五行权重偏向、大运步长、

六爻起卦法、动爻规则、六神映射、神煞池大小。

个体命盘由 `种子 + 注册名 + 维度 + 坐标 + 局部索引` 推出。

局部索引是「这一格里的第几只」，因为同一格可能站着两只僵尸。

**六爻状态影响 AI 权重**（用属性修正器实现，不是改 AI 目标）：

| 状态  | 效果                |
| --- | ----------------- |
| 官鬼旺 | 移速、攻击、追击范围上调——更激进 |
| 子孙旺 | 移速、追击范围下调——更保守    |
| 兄弟旺 | 移速额外上调——更爱集结      |
| 妻财旺 | 影响村民的交易价格         |
| 父母旺 | 护甲上调——更耐打         |

用固定的 `Identifier` 做修正器 id，重复挂只更新不叠加，不会出现「越跑越快」。

**窥命要付代价**：每天看太多会开始反噬。

### 4.6 建筑命理

原版建筑（村庄、神庙、要塞、矿井、前哨、海底神殿、林地府邸、远古城市、

试炼密室、废弃传送门、下界要塞、堡垒遗迹、末地城、末地船）

每一座都有自己的八字、本命卦、风水与**每日状态**（吉 / 平 / 凶 / 大凶）。

命盘由 `种子 + 类型 + 维度 + 锚点坐标` 推出，所以同一座村庄在任何人眼里都是同一个命。

日主五行决定**建筑气质**，进而决定内部生物强度倍率与战利品倾向。

结构受损，但稀有战利品反而更容易出现。这是给敢去的人的回报。

### 4.11 三大术数：紫微 · 六壬 · 奇门

前九章讲的命理、风水、六爻，回答的是「我是什么命」「这块地怎么样」「这件事会怎样」。  
三大术数回答的是另外三个问题：

| 术数       | 问什么  | 骨架          | 输出     |
| -------- | ---- | ----------- | ------ |
| **紫微斗数** | 你是谁  | 十四主星落十二宫    | 一张四方命盘 |
| **大六壬**  | 事怎么走 | 四课三传 + 十二天将 | 一条发展线  |
| **奇门遁甲** | 往哪走  | 九宫 + 八门九星八神 | 一个方位   |

三门都不是「随机吐一句话」——它们各有完整的排盘算法。

#### 紫微斗数（`ziwei` 包）

排盘五步，一步不减：

1. **定命身宫**：寅起正月顺数到生月，再从生月宫起子时逆数到生时（命宫），顺数则是身宫；
2. **定五行局**：命宫干支取**纳音** → 水二局 / 木三局 / 金四局 / 土五局 / 火六局；
3. **起紫微**：商余法 —— `商 = ⌈日 ÷ 局⌉`，`余 = 商 × 局 − 日`，  
   余数为偶则从寅顺行、为奇则逆行（水二局初一紫微在丑、木三局初一在辰，与原书对得上）；
4. **安十四主星**：紫微系逆行（紫微→天机→太阳→武曲→天同→廉贞），  
   天府与紫微关于寅申轴对称，天府系顺行（天府→太阴→贪狼→巨门→天相→天梁→七杀→破军）；
5. **布十二宫**：命宫起逆布兄弟、夫妻、子女、财帛、疾厄、迁移、交友、官禄、田宅、福德、父母。

盘面按传统四方盘排（上排巳午未申、下排寅丑子亥），中间留空给五行局与命主身主。  
**命宫若有双星同宫会特别标出** —— 那是整张盘最值得看的一格。

#### 大六壬（`liuren` 包）

1. **月将加时**：正月（寅）用亥将，逐月退一位；把月将摁在时辰那一格上，天盘就转起来了；
2. **四课**：日干寄宫（甲寄寅、乙寄辰、丙戊寄巳、丁己寄未、庚寄申、辛寄戌、壬寄亥、癸寄丑）  
   起一课二课，日支起三课四课；
3. **发用**（初传）四级兜底：
   - **贼克** —— 先取下贼上（下神克上神），无则取上克下；
   - **比用** —— 候选多于一个时，取与日干同阴阳者；
   - **遥克** —— 四课无克，看上神与日干谁克谁；
   - **昴星** —— 仍无，阳日取酉宫、阴日取其冲；
   - 另有**伏吟**（月将＝时支）与**返吟**（相差六位）两种特殊处理；
4. **三传**：初传之上神为中传，中传之上神为末传；
5. **十二天将**：甲戊庚牛羊、乙己鼠猴乡、丙丁猪鸡位、壬癸兔蛇藏、六辛逢马虎；  
   昼用阳贵、夜用阴贵；贵人临地盘亥至辰顺布、临巳至戌逆布。

课体按「三传所乘天将的吉凶 + 三传递生/递克 + 四课贼克数」打分。  
**吉将连传则事顺，凶将连传则宜守** —— 这条直觉被保留成了评分规则。

#### 奇门遁甲（`qimen` 包）

1. **阴阳遁**：一年 360 日，前 180 日阳遁、后 180 日阴遁（冬至后阳、夏至后阴）；
2. **局数**：五日一元，一元换一局，一至九局循环；
3. **地盘三奇六仪**：戊己庚辛壬癸丁丙乙，阳遁顺布九宫、阴遁逆布；
4. **时干定位（甲遁六仪）**：时干是甲时，用旬首所遁的仪 ——  
   甲子戊、甲戌己、甲申庚、甲午辛、甲辰壬、甲寅癸。**这一步最容易漏，也最影响结果**；
5. **值符值使**：时干所落之宫的本位星为值符、本位门为值使，其余九星八门八神顺逆加临；
6. **定方位**：九宫里生门、开门、休门落在哪一宫，就对应罗盘上的哪个方向。

输出是一张 3×3 的九宫格（上南下北），每格写「星 门 神 · 干」，  
下面单列三吉门各自的方位与宜忌，最后给一句「此局最旺在何方」。

#### 三张盘 · 九道符 · 三座坛

| 道具       | 用途    | 附赠                          |
| -------- | ----- | --------------------------- |
| **紫微命盘** | 排一张命盘 | 按「哪一宫最盛」给抗性 / 幸运 / 力量 / 速度  |
| **六壬式盘** | 起一课   | 三传通顺给幸运与再生；滞涩时只延长冷却，**不惩罚** |
| **奇门局盘** | 起一个局  | 生门给再生与饱食、开门给幸运、休门给抗性        |

| 门派 | 三道符             | 效果                      |
| -- | --------------- | ----------------------- |
| 紫微 | 紫微令 / 天府令 / 七杀令 | 抗性+生命提升 / 饱和+幸运 / 力量+速度 |
| 六壬 | 贵人符 / 青龙符 / 白虎符 | 幸运+再生 / 速度+跳跃 / 力量+急迫   |
| 奇门 | 生门符 / 开门符 / 休门符 | 再生+饱食 / 幸运+夜视 / 抗性+吸收   |

三座**术坛**（紫微星台 / 六壬式坛 / 奇门局阵）同时扮演两个角色：

- **查询台** —— 右键起盘，冷却只有随身法器的一半（固定装置总比手上那件顺手）；
- **工位** —— 摆一座坛，附近的失业村民会转职成 **星命师 / 课师 / 局师**，  
  三级交易卖对应门派的盘与符。

> 三张盘都是「九宫围一核」合成的：八枚术料包住一件旧物  
> （星尘 + 命盘玉简 / 课甲 + 龟甲 / 遁甲残片 + 阴阳石）。  
> 术坛再拿盘去镶。链条是刻意做长的 —— 想自己开一间术馆，得先有盘。

## 五、三层信息设计：不懂命理也能玩

> **核心原则：玩家不需要懂命理，只需要会玩游戏。**
>
> 系统在后台算，前台只给玩家能懂的反馈。懂的人可以深挖，不懂的人照样通关。

### 信息分三层

| 层级       | 面向   | 内容            |
| -------- | ---- | ------------- |
| 第一层 · 直感 | 所有人  | 颜色、粒子、音效、屏幕边框 |
| 第二层 · 白话 | 普通玩家 | 一句人话提示        |
| 第三层 · 术语 | 硬核玩家 | 八字、卦象、六亲六神    |

**默认只显示前两层**。第三层需要玩家在第 29 天解锁"专业模式"后自行打开。

举两个例子：

**风水罗盘**——

- 第一层：屏幕边缘泛绿光 = 好，泛红光 = 差（脚下还会撒金/黑粒子）
- 第二层："这地方不错。可以在这里安家。气聚，这地方舒服。"
- 第三层："气 +42 煞 +15 阴 +20 阳 +35，评级吉"

**六爻起卦**——

- 第一层：卦盘六路红石信号、界面背景色
- 第二层："往西南走，地下有矿，小心岩浆。这事很顺，放手去做。"
- 第三层："地天泰变雷天大壮，妻财持世，白虎临二爻"

### 新手引导：任务链，不是教程

不弹长篇说明。按游戏日（离线不计时）推进：

| 游戏日    | 发生什么                                     |
| ------ | ---------------------------------------- |
| 进入世界   | 自动获得命盘玉简，一句话："你是土属性的人，像大地一样稳重……按 B 随时查看" |
| 第 2 天  | 获得风水罗盘："右键看看脚下这块地怎么样"                    |
| 第 4 天  | 获得三枚铜钱："右键掷一卦，问一件事"                      |
| 第 9 天  | 获得观气台与寻龙尺                                |
| 第 14 天 | 命盘显示完整四柱                                 |
| 第 19 天 | 卦象显示六亲六神、流年大运                            |
| 第 29 天 | 解锁专业模式                                   |

每解锁一层弹一次简短提示，不强制、不阻塞、可以忽略。

引导可以用 `tutorialEnabled: false` 一键关闭（老玩家/服务器用）。

### 内置帮助

不做 Wiki，帮助就在物品上：

- **命盘玉简** Shift+右键 → "你的日主是戊土，代表你像大地一样稳重……"
- **风水罗盘** 潜行+对门右键 → 颜色图例
- **起卦器具** Shift+右键 → 怎么问卦
- 首次遇到新概念 → 聊天栏一句话提示


### 视觉反馈（能用图形就不用文字）

- **屏幕边框**：站在吉地泛金光/绿光，凶地泛橙光/红光，带呼吸动画 —— 不读一个字就知道这地方好不好
- **地面粒子**：吉地撒金色粒子，凶地冒黑烟
- **音效**：吉地水晶声，凶地低沉心跳声
- **卦盘**：六个面各输出一路爻位红石信号

### 容错设计

不懂的人会做错，错了不能惩罚太重：

- **风水差**：只是减益，不是不能玩
- **卦象错**：只是没找到，不是死亡
- **违反宜忌**：只是小概率招煞，不是必死
- **问卦过多**：只是模糊，不是禁用
- **保底**：连着 3 次凶卦，送一次真实的吉运（幸运效果 + 粒子）—— 注意卦本身不动，保底是额外补偿，不破坏确定性
- **新手保护期**：前 3 个游戏日，风水减益大幅缩短且不掉血
- **任何时候**都能用轮回台重来

### 可选深度

| 玩家类型 | 体验                   |
| ---- | -------------------- |
| 完全不懂 | 看颜色、跟提示，照样通关         |
| 略懂   | 看白话提示，理解风水吉凶、卦象方向    |
| 很懂   | 开专业模式，看四柱、六亲、旺衰，精确规划 |
| 硬核   | 研究种子、算龙脉、布八卦阵、逆天改命   |

一句话总结：**后台算复杂的，前台给简单的。**

玩家看到的是"往西走，地下有矿，小心岩浆"，而不是"地天泰变雷天大壮，妻财持世"。

## 七、配置

第一次启动会在 `config/yishu.json` 生成配置文件，纯 JSON，可直接改：

```json
{
  "randomness": "MEDIUM",          // 随机性等级：LOW / MEDIUM / HIGH / CHAOS
  "allowBirthInput": true,          // 是否允许输入自己的生辰
  "fateVisibility": "SELF",         // 命盘可见性：SELF / AUTHORIZED / PUBLIC
  "fengShuiEnabled": true,
  "dragonVeinEnabled": true,
  "taiSuiEnabled": true,
  "dailyAlmanacEnabled": true,
  "divinationDailyLimit": 3,        // 每日问卦上限
  "backlashEnabled": true,          // 超限是否反噬
  "externalOmenEnabled": true,      // 是否允许外应起卦
  "mobFateEnabled": true,
  "buildingFateEnabled": true,
  "ruinsEnabled": true,
  "overworld": { "fate": true, "fengShui": true, "liuYao": true },
  "nether":    { "fate": true, "fengShui": true, "liuYao": true },
  "end":       { "fate": true, "fengShui": true, "liuYao": true }
}
```

改配置**不会**影响「同种子同结果」这条铁律——它改的是「哪些系统生效」，

不是「算出什么数」。把风水关了，卦还是同一卦；把随机性等级调高，命盘还是同一张命盘。

这两类东西必须严格分开，否则「可复现」就成了空话。

### 三个关键设计决定

**1. 只同步种子，不同步结果。**
客户端的命盘、神煞、大运、黄历全部本地计算——因为整套推算本来就是确定性的，
服务端和客户端算出来的必然一致。所以整个模组只有三个网络包：
种子、显示面板、起卦请求。这既省带宽，也让界面响应零延迟。

**2. 通用文本面板而不是一堆自定义 GUI。**
卦象、户型图、命盘、报告都显示在同一块「玄览」面板里。
内容系统一定会不断加新东西，如果每加一个就要写一个 GUI，开发量会指数级膨胀。
真正需要定制的只有两个界面（命盘与起卦），那两个做了专属界面。

**3. 每个注册点单独 try/catch。**
任何一个模块在某个小版本上失效，也只让那一个功能消失，而不是让游戏起不来。
这条纪律在 26.x 这种快速演进的版本线上尤其值钱。

## 九、构建

```bash
# 需要 JDK 25 + Gradle 9.8 及以上
gradle build

# 产物在 build/libs/ 下，同时会收集一份到 dist/
ls dist/
```

> 本仓库暂未附带 Gradle Wrapper 的二进制 jar（避免仓库里塞一个 60 KB 的
> `gradle-wrapper.jar`）。用系统 Gradle 9.8+ 即可；想用 wrapper 的话，
> 在仓库根目录跑一次 `gradle wrapper --gradle-version 9.8.0` 就会生成。

生成数据与资源（可选，仓库里已经包含生成好的成品）：

```bash
python tools/generate_vanilla_data.py    # 结构 / 交易 / 配方 / 进度 / 标签
python tools/generate_assets.py          # 纹理 / 模型 / 方块状态 / 语言 / 图标
python tools/gen_oracle_realms.py        # 三术界维度：维度 / 群系 / 树 / 矿 / 神殿
python tools/generate_entity_textures.py # 灵兽换色贴图（读原版贴图重上色）
python tools/validate_templates.py       # 结构模板全量校验（改完数据必跑）
python tools/validate_worldgen.py        # 维度 / 群系 JSON 校验（改完 worldgen 必跑）
```

两个脚本要读原版 jar 才能工作，路径用环境变量指定：

```bash
export YISHU_MC_JAR=/path/to/.minecraft/versions/26.2/26.2.jar
```

`generate_assets.py` 会打印生成了多少文件，并校验中英语言文件的键集合是否一致——
漏键在游戏里会显示成原始 key，是个很容易漏掉的坑。

真机验证脚本走 RCON，密码同样从环境变量读：

```bash
export YISHU_RCON_PASSWORD=<测试服务端 server.properties 里的 rcon.password>
python tools/rcon_probe.py
```

产物：`dist/yishu-1.0.0+26.2.jar`（约 1.67 MB / 2356 个条目）。

## 十、已知边界

诚实列出这一版**没有**做的部分，免得以为是 bug：

1. **巨构的实机表现尚未逐座走查**——结构模板已通过解析级全量校验
   （尺寸 / 越界 / 调色板 / 实体格式 / 全量 JSON），但浮空岛、放大化地形上的实际观感
   还需要进世界逐座看一遍。
2. **灵兽是「原版模型 + 专属换色贴图 + 自定义 AI 目标」**——没有从零建模，
   好处是随版本升级几乎零维护。
3. **作物生长与刷怪率的直接挂钩**——风水效果目前通过状态效果体现
   （幸运、恢复、黑暗、虚弱、急迫），还没有 hook 原版生长与生成逻辑。
4. **15 个群系的植被密度、11 种树的林相、12 种灵兽的刷怪手感**——
   数据层已全部校验通过（群系 features / 特征引用 / 刷怪规则），
   但实机观感（树是稀是密、灵兽是多是少）建议进世界走一圈，按体感微调。
5. **建筑渡劫的结构侵蚀**——渡劫状态会影响刷怪与战利品，但还没有真的去破坏建筑本身。
6. **界域地形**——浮空岛 / 放大化来自原版噪声设置，尚未做专属地形雕刻。
